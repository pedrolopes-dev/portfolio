# 💻 Meu Portfólio Pessoal

Seja bem-vindo(a) ao repositório do meu **Portfólio Web**! 🚀

Este projeto foi desenvolvido com o objetivo de apresentar meus conhecimentos em desenvolvimento web, projetos práticos e minha evolução contínua como desenvolvedor. Ele funciona como uma vitrine interativa das minhas habilidades técnicas e do meu trabalho.

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído do zero utilizando as seguintes tecnologias:

- **HTML5**: Estruturação semântica e acessível das páginas.
- **CSS3**: Estilização, design responsivo e efeitos visuais.
- **JavaScript (ES6+)**: Lógica, interatividade e dinamismo na interface.
- **Git & GitHub**: Controle de versão e hospedagem do código.

---

## 📌 Principais Funcionalidades

- **Apresentação Pessoal**: Resumo profissional e objetivos na área de tecnologia.
- **Projetos**: Exibição dos principais projetos desenvolvidos com links diretos para os repositórios e demonstrações.
- **Design Responsivo**: Interface adaptada para navegação em computadores, tablets e smartphones.
- **Contato**: Seção dedicada com links para minhas redes profissionais e canais de comunicação.

---

## 🚀 Objetivo do Projeto

Desenvolver este portfólio me permitiu consolidar conceitos fundamentais de desenvolvimento *front-end*, boas práticas de organização de código e criação de layouts responsivos. Além disso, o projeto está em constante evolução conforme aprendo novas tecnologias e aprimoro minhas habilidades.
